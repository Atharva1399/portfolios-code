# Atharva's Minimal Portfolio

A retro minimal dark-blue portfolio built with Vite, React, TypeScript, and Tailwind CSS.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Run the development server:
   ```sh
   npm run dev
   ```

## Technologies Used

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

## Deployment

You can deploy this project on any static hosting provider like Vercel, Netlify, or GitHub Pages.
